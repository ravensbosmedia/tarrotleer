# Foto-verzameling Mystieke Lenormand

36 verkleinde versies (400px breed, ~37 KB elk) voor gebruik in de UI.

**Originelen (1.2 MB elk, scans van het dek)** zijn NIET in deze repo opgenomen
i.v.m. bestandsgrootte en copyright. Bewaar die apart (USB / Drive).

Bij herstel: deze fotos worden direct gekopieerd naar
`/var/www/auraline-frontend/lenormand-fotos/` op de server.
